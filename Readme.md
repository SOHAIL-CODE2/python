# 🔐 Secure Employee Account System

A console-based employee account management and authentication system built with Python.

## Features

* Create multiple employee accounts
* Unique username validation
* Password strength validation
* Minimum 8-character password requirement
* Uppercase, lowercase, digit, and special-character validation
* Duplicate credential checking
* Password confirmation
* Employee login authentication
* Maximum 5 login attempts
* Access denial after maximum failed attempts
* User-friendly validation error messages

## Python Concepts Used

* Dictionary
* Lists
* `for` and `while` loops
* Nested conditions
* String methods
* Boolean flags
* Input validation
* `break` and `continue`
* Authentication logic

## Learning Outcome

This project was created to strengthen Python fundamentals by combining loops, conditions, dictionaries, string handling, and validation logic into a practical console-based application.
